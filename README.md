# チョイス

## サイト概要
### サイトテーマ
実際に食事に行ったところについて  
情報提供や意見交換ができるレビューサイト
​
### テーマを選んだ理由
食事に行く際に様々なお店があるので、  
どのお店がよいか迷うことがあります。  
実際に食事に行った人に情報や意見が聞けるサービスがあれば、  
お店に行ったことがない方でも有効に活用できるのではと考えました。  
食事だけでなく、ワンハンドの料理や屋台でも選択できるようにする為、このテーマにしました。

### ターゲットユーザ
- お店に行ったことがない方で、実際に食事に行ったレビューを参考にしたい人
- 行先で行きたいお店が明確にできず、情報を求めたい人
​
### 主な利用シーン
- 行先で行きたいお店を検索する時
- 実際に食事に行った方の情報や意見を参考にしたい時
- 自分が食事したお店のレビューを投稿したい時
